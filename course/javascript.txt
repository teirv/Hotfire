=U vars | Variables
=L boxes | Boxes with names
@T
A **variable** is a labeled box that holds a value. You put something in once, then use the label whenever you need it.

`let` means "make a new box." The `=` means "put this value inside."
~code
let age = 30;
console.log(age);
@T
Important detail: in code, `=` does **not** mean "equals." It means **store**. Read it right to left: take `30` and store it in `age`.

No quotes around a variable name. Quotes would give you the word itself.
~code
let city = "Waco";
console.log(city);
console.log("city");
@P
What does this print?
~code
let food = "tacos";
console.log(food);
~opts
* tacos
- food
- "tacos"
~why
With no quotes, `food` is the variable's name, so you see what is inside the box.
@T
Boxes made with `let` can get new values. Leave off `let` the second time, because the box already exists.

The old value is replaced.
~code
let score = 10;
score = 25;
console.log(score);
@P
What does this print?
~code
let lives = 3;
lives = 2;
lives = 1;
console.log(lives);
~opts
* 1
- 3
- 6
~why
Each `=` replaces what was in the box. The last value stored was `1`.
@T
Use `const` for a box that should never change, like a birthday. Trying to change it gives an error, which protects you from mistakes.

A good habit: use `const` by default, and `let` only if the value needs to change.
~code

console.log(birthYear);

You are storing a score that goes up during a game. Which keyword fits?
~opts

=L forloop | Repeat with for
@T
A **loop** runs the same code many times, so you don't have to write it over and over.

This `for` loop prints 1, 2, 3. Run it, then we will go through its three parts.
~code

**Start:** `let i = 1` makes a counter.

**Keep going while:** `i <= 3` is checked before every round.

`i` is the traditional name for the counter. It stands for index.
~code
for (let i = 0; i < 5; i++) {

}

* 4
- 3
- 5
~why

=L whileloop | Repeat with while
@T
A `while` loop keeps going as long as its condition is true. Use it when you don't know how many rounds you need.

It is like saying: "while the tank isn't full, keep filling."
~code
let tank = 0;

while (tank < 100) {
  tank += 30;
  console.log(tank);
}
@T
Careful: something inside the loop must change, or the condition stays true forever. That is an **infinite loop**.

Here it would be `count` never going up. If that happens here, the app stops your code after a few seconds.
~code
let count = 3;

while (count > 0) {
  console.log(count);
  count--;
}
console.log("Liftoff");
@P
What is the last line printed?
~code
let n = 1;
while (n < 8) {
  n = n * 2;
  console.log(n);
}
~opts
* 8
- 4
- 16
~why
`n` goes 2, 4, 8. At 8 the condition is false, so the loop ends.
@T
`break` jumps out of a loop right away. `continue` skips to the next round.
~code
for (let i = 1; i <= 5; i++) {
  if (i === 2) {
    continue;
  }
  if (i === 4) {
    break;
  }
  console.log(i);
}
@T
Loops can go through a string one letter at a time. `word.length` gives the stopping point, and `word[i]` gets each letter.
~code
let word = "go";

for (let i = 0; i < word.length; i++) {
  console.log(word[i]);
}

// Your while loop here

=U funcs | Functions
=L define | Make your own command
@T
A **function** is a named set of steps. You write it once and then use it whenever you want, like a saved recipe.

Writing it is called **defining**. Using it is called **calling**. Nothing happens until you call it.
~code
function greet() {
  console.log("Hello there");
}

greet();
greet();
