=L pyprac0 | How the practice test works
@T
Each problem is like one on your exam: read the task, write the whole program, and match the sample output **exactly**, including capitals, spaces and punctuation.

**Input:** use `input()` with nothing inside the parentheses. Samples show lines like `Enter index:`, but that's the console asking. It isn't part of the output, so adding it would make your output wrong.

**Run** uses the first sample input. **Check** tests every input listed under **What Check tests**, so your program has to work for any value, not just the sample.

Stuck on an idea? Use the **Review** buttons next to each problem to reopen the lesson that teaches it. Your place in the test stays put.
@Q
The sample says `Enter base 1: 3`. Which line reads that value correctly for the exam?
~opts
* `b1 = int(input())`
- `b1 = int(input("Enter base 1: "))`
- `b1 = input()`
~why
No prompt text, so nothing extra gets printed. `int()` turns the text into a number.
