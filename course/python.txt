`//` is floor division and drops the remainder.

for i in range(1, 3):

=L pylists | Lists
@T
A list holds items in order, and it can change. Indexing and slicing work like strings.

`append` adds to the end. `insert` adds at a position. `remove` deletes by value. `pop` deletes by position (last by default).
~code
parts = ["valve", "seal"]
parts.append("hose")
parts.insert(0, "pump")
print(parts)

parts.remove("seal")
last = parts.pop()
print(last, parts, len(parts))
@T
Useful helpers: `sum`, `max`, `min`, `sorted`, `.sort()`, `.reverse()`, `in`.

`sorted()` gives back a new list. `.sort()` changes the list in place and returns `None`.
~code
nums = [3, 1, 2]

print(sum(nums), max(nums), min(nums))
print(sorted(nums), nums)

nums.sort(reverse=True)
print(nums, 2 in nums)
@T

That bug shows up on tests.

print(a)

c.append(4)
print(a, c)

**12. Append a sentence to a file**

Prompt for a file name with `Enter the name of the input file:` followed by a newline. The file contains exactly three lines with one word per line. Use `open()` and `read()` to get the words, join them in order with one space between each word, and use `write()` to append the sentence on a new line. Print the complete updated file.

Hotfire provides a fresh copy of the file for each run. Sample input: `WordTextFile.txt`
```
cat
chases
dog
```
Expected console:
```
Enter the name of the input file:
cat
chases
dog
cat chases dog
```
~start
# Your code here
~sol
name = input("Enter the name of the input file:\n")
with open(name, "r") as file:
    contents = file.read()

sentence = " ".join(contents.split())
with open(name, "a") as file:
    if not contents.endswith("\n"):
        file.write("\n")
    file.write(sentence + "\n")

with open(name, "r") as file:
    print(file.read(), end="")
~hint
